> أول أصل في نيتش المختار (D-012). النص الكامل في `SKILL.md`.

## نشرها على skills.sh (خطوات المالك)

1. أنشئ مستودع GitHub عامًا جديدًا (مثل `yours/agent-skills`).
2. ضع الملف بهذا الشكل داخل المستودع:
   ```
   launch-audit/SKILL.md
   ```
3. اختبر محليًا: `npx skills add <owner>/<repo>` — يجب أن تُكتشف المهارة وتُثبَّت.
4. skills.sh تلتقط المستودعات المثبتة تلقائيًا عبر عدّاد `npx skills` — التحية الأولى تأتي من أول تنصيب حقيقي.
5. بعد النشر: سجّل التاريخ والرابط في `system/state/decisions.md` (مراجعة D-012 عند أول 100 تنصيب).

## لغة «use when» في الوصف (متطلبة من كتلة 16)

الوصف في الـfrontmatter يبدأ بـ«Pre-launch readiness audit… Use when…» — هذا ما يجعل الوكلاء يجدونها عند الحاجة الفعلية، وهو جسر البيع للوكلاء نفسه: **الوصف هو الإعلان**.
